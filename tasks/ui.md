# UI

Tasks for creating and managing user widgets.

| Task | Description |
|------|-------------|
| [Create Widget](/tasks/create-widget) | Creates a `UUserWidget`, optionally adds it to the viewport, and outputs the created widget reference. |
| [Call Widget Event](/tasks/call-widget-event) | Calls a BlueprintCallable or Blueprint Event function on a bound widget by name, with auto-populated parameters. |
| [BindWidgetEvent](/tasks/bind-widget-event) | Listens to one selected widget event on a bound widget and forwards it into StateTree as either a delegate trigger or a typed StateTree event. |
| [WaitForWidgetDelegate](/tasks/wait-for-widget-delegate) | Wait for a Blueprint event dispatcher on a bound widget, publish supported payload outputs, then complete. |
| [Set Input Mode: Game Only](/tasks/set-input-mode-game-only) | Sets input mode to game only on a bound player controller. |
| [Set Input Mode: UI Only](/tasks/set-input-mode-ui-only) | Sets input mode to UI only on a bound player controller, with optional widget focus and mouse lock behaviour. |
| [Set Input Mode: Game And UI](/tasks/set-input-mode-game-and-ui) | Sets input mode to game and UI simultaneously on a bound player controller, with optional widget focus, mouse lock, and cursor capture behaviour. |
