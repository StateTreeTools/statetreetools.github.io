# Get Game Mode

**Plugin:** StateTreeToolsCore
**Category:** Game
**Availability:** StateTree Tools **3.0+**

Returns the current world's game mode. This mirrors Unreal's Blueprint **Get Game Mode** node.

---

## Output

The current `AGameModeBase`. This is only valid on the authority side where the game mode exists.

## Unreal Engine Version Notes

Property functions are not available in UE 5.4. This node requires **UE 5.5 or later**.
